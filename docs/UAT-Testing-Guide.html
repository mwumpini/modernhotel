Ghana Hotel Management

User Acceptance Testing (UAT) Guide · Version 1.0 · June 2026
Production URL: https://ghana-hotel-management.vercel.app

1. Purpose

This guide walks testers through the main hotel processes on the live deployed app so critical flows are not missed before the next development phase.

Time: 45–60 minutes per person (focus on one role).

2. Before you start

ItemInstruction
BrowserChrome or Edge on a laptop (desktop layout).
Private windowUse Incognito/Private mode for a clean start.
InternetStable connection required.
Data noteData is stored in your browser for now. Other devices won’t see your test reservations. Expected.
ScreenshotsCapture every error, blank screen, or wrong total.

3. How to report issues

  1. Tester name & date/time
  2. Module (Front Office, F&B, Accounting, etc.)
  3. Steps (in order)
  4. Expected vs Actual
  5. Severity: Blocker / Major / Minor / Suggestion
  6. Screenshot attached

Test A — First visit & setup (~10 min)

Everyone. Goal: app loads and setup completes.

  1. Open https://ghana-hotel-management.vercel.app
  2. If redirected to Setup, complete the wizard (hotel name, Ghana, GHS, finish).
  3. Confirm main dashboard with sidebar appears.
  4. Open Help (/help) — must load.

Pass: Setup completes, no crash.

Fail: Blank screen, endless loading, unrecoverable error.

Test B — Front desk: reservation → check-in → checkout (~20 min)

Role: Reception / Front Office
Link: /guest-services/check-ins

B1 — Create reservation

  1. Reservations / Bookings tab → New reservation.
  2. Guest: Test Guest [your initials], arrival today, departure tomorrow, confirmed.
  3. Save; confirm it appears in the list.

B2 — Check in

  1. Today’s Arrivals → Check in your guest.
  2. Assign room if prompted; status = checked-in.

B3 — Folio charge

  1. Open guest folio; add charge (e.g. Laundry GHS 50).
  2. Confirm balance increases.

B4 — Check out

  1. Check-outs tab → check out guest.
  2. Note final total; complete payment if prompted.

Pass: Full stay cycle without error.

Test C — F&B POS (~15 min)

Role: Restaurant / Bar · Sidebar → Food & Beverage → POS

C1 — Walk-in cash sale

  1. Walk-in order, add items, pay Cash or Card, complete.

C2 — In-house room charge

  1. In-house guest order, pay Room Charge (not cash).
  2. Complete sale.

Report if: duplicate accounting or folio looks wrong after room charge.

Test D — Night audit & no-show (~15 min)

Role: Night Manager · Front Office → Night Audit

  1. Review Room Configuration → Night Audit settings (auto-run on, first night at check-in off = default).
  2. Run Night Audit manually; note room charges posted.
  3. Optional: create today’s reservation, do not check in, mark No-show.

Known: Auto audit at 1:00 AM only if browser tab stays open overnight.

Test E — Accounting (~15 min)

Role: Finance · Sidebar → Accounting

  1. Accounts Receivable: New sales invoice (Posted), e.g. GHS 1,000.
  2. Receipt: Record payment on invoice.
  3. Financial Reports: Open Income Statement or Trial Balance — must render.

Test F — Room configuration (~10 min)

  1. Room Configuration → view types & night audit policies.
  2. Rate Management → rates load for room types.
